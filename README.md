# Knightsbridge Events — Nexora concept website

A responsive React + Vite concept prototype for a premium event planning and coordination brand.

## Run
1. Install Node.js (or open/import this project in StackBlitz).
2. Run `npm install`.
3. Run `npm run dev`.

## Before presenting or launching
- This is a concept demonstration, not a completed client website.
- Event photography is illustrative stock imagery, not Knightsbridge Events' own portfolio.
- Replace the WhatsApp placeholder `233XXXXXXXXX` in `src/main.jsx` with the approved business number.
- The enquiry form is a front-end demo only. Connect a form backend or CRM before launch.
- Confirm the final brand direction, services, business details, copy, imagery and domain with the client.
- Do not present sample images or wording as completed client projects or testimonials.
